## Sobre o projeto

Projeto de estudos focado na criação e customização de **componentes Card** em React.

Explora padrões de componentização, reutilização e diferentes estilos de cards para diversas aplicações.

---

## Funcionalidades

- 🃏 Componentes Card reutilizáveis
- 🎨 Diferentes variações de estilo
- 📱 Design responsivo
- ⚙️ Props customizáveis
